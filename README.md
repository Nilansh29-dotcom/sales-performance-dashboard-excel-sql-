#  Sales Performance Dashboard (Excel + SQL)

##  Overview
This project focuses on analyzing retail sales data to track business performance and generate actionable insights.

##  Tools Used
- Microsoft Excel (Pivot Tables, Charts, Slicers)
- SQL (Data Extraction & Cleaning)

##  KPIs
- Total Sales
- Total Profit
- Total Orders
- Profit Margin

##  Dashboard Features
- Sales by Region
- Profit by Category
- Monthly Sales Trend
- Top Customers
- Interactive Slicers (Region, Category)

##  Key Insights
- West region generates the highest revenue
- Technology category contributes the most profit
- Sales show a consistent upward trend over time
- A small group of customers contributes a large share of total sales

## Files Included
- dashboard.xlsx
- dataset.csv
- queries.sql
  
##  Conclusion
The dashboard enables quick analysis of business performance and supports data-driven decision-making.
